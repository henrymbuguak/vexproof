Which of your dependency alerts can actually reach your code?

Scanners list every advisory for every package you install. vexproof reads your code and each advisory's fix, then settles each alert with evidence: a verified call path from your code to the vulnerable function, or proof that its module never loads.

Muse Spark proposes which function an advisory is about and judges uncertain steps. A verifier checks every step before anything is reported.
