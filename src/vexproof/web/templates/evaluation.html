What this shows, and what it does not

  • A run can contradict a clear but never prove one: a module that did not load here might load under other use. The stronger check is the closure: every module that loaded had to be one the scan said could load.
  • A vulnerable function that ran shows the call path is real, not that an exploit works. One that did not run was not exercised by this script; that is not evidence against the path.
